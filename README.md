# SQLInjection-Multiclass-Classification
Multiclass SQL injection detection and classification using machine learning models

SQLInjection-Multiclass-Classification

Research Title

Multiclass SQL Injection Attack Classification Using Machine Learning Models

Dataset Used

* HttpParams Dataset
* 30,156 HTTP parameter samples
* Seven SQL injection attack categories

## Machine Learning Models Used

* Random Forest
* Gradient Boosting
* Support Vector Machine (SVM)
* Multi Layer Perceptron (MLP)

## Technologies Used

* Python
* Scikit learn
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Repository URL

https://github.com/Solexy001/SQLInjection-Multiclass-Classification

## How to Run the Code

### 1. Clone the Repository

```bash
git clone https://github.com/Solexy001/SQLInjection-Multiclass-Classification.git
```

### 2. Navigate to the Project Directory

```bash
cd SQLInjection-Multiclass-Classification
```

### 3. Install Required Packages

```bash
pip install -r requirements.txt
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook SQLi_Multiclass_Classification.ipynb
```

## Research Objective

This research aims to develop a machine learning framework capable of classifying different SQL injection attack types using leakage free statistical and structural features.
